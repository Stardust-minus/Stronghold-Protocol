# 实验性多人好友房

本 fork 在普通四人同盟之外提供默认关闭的好友房人数扩展。它不改变公开匹配的人数，也不拆成不同玩家分区。此说明描述本地实现；上线状态以实际发布记录为准。

## 使用

1. 创建普通好友同盟，在房间的“实验性选项”中启用“扩展同盟人数”。
2. 房主选择 8、10、16 或 20 人上限；不要求补满，真人与 AI 合计不能超过上限。
3. 所有成员须使用支持此功能的新页面。旧客户端仍可使用普通房间，但不能加入或恢复扩展房间。
4. 开启后禁用组队匹配，哪怕房间只有一两人。普通公开匹配始终四人，好友小队排队须其他真人队友全部在线并已准备；房主发起匹配视为房主准备。
5. 开局后不能改规则。缩容不会移位或踢人：目标上限以外有真人或 AI 时拒绝。改动规则会清除其他真人的准备状态。

扩容只能在好友房设置，不能在公开匹配结束后的房间开启。独立模拟仍一人；观战席与参战人数分开，保留本 fork 原观战规则。

## 玩法边界

- 普通战斗仍每人一个棋盘；领袖战按座位两两配对，奇数末位独占。整阶段仍共享同一领袖 HP 与团队 LP 权威，不能将每个场地当成独立血池。
- 5／6 人开局共用一个扩容卡池，副本数为 `ceil(原数量 × 实际人数 / 4)`。7 人起均衡分组，每组不超过四人，三人组也保留完整原卡池；死亡或退出后不重新分组。
- 禁用共享卡池的个人库存优先，自选编队库存仍属于本人；跨组赠送从接收者的库存取副本。
- 实验模式实际存活人数超过四人时，机变提供存活人数加两张选项，最多 22 张；重复卡按不同位置独立选择。普通四人及以下的抽取和随机序列保持原样。
- 实验模式超过四人的领袖血量按存活人数／4 缩放，隐藏核心门槛按最终攻势开始时的人数快照缩放。战中退出沿用本站原机制，不引入远端动态重缩血池。
- 普通四人及实验局实际存活不足八人仍单轮联防、最多两名帮手。仅扩容实验局在普通战斗开始及联防开始时都至少八人存活，第一轮有残余且还有合格帮手时，启用第二轮接力：另一组最多两名未参加第一轮、普通战斗无漏怪且仍存活的帮手处理残余，不重打已击倒的敌人。两轮均沿用本局原地图与各帮手普通战斗结束时的生命／技力状态；最后统一扣一次漏怪者生命，保留两轮收益、击杀和伤害账本。不加入跳过投票或额外客户端战斗权威消息。
- 队友复活保持生命至少 11、支付 10，目标抵消死亡、回到 1 点生命，保留原阵容和状态，每人每局一次。接力局从两轮实际参与且普通战斗、本人联防半场均无计数漏怪的帮手中确定救援资格；没参战的预备帮手不能支付救援，第一轮不提前扣命或开启救援。

大人数会增加轮选等待和演算量。第二轮接力缓解最多两名帮手同时承担大量漏怪的瓶颈，但只在仍有合格帮手时提供补救，不能保证 16／20 人与四人局完全等难。当前为未发布的本地候选，完整多人平衡性验收尚未完成；受控波次的真实 Worker／浏览器验证也不是自然多人完整通关、二十台设备、生产容量或性能保证。
