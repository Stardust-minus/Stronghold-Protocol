# 干员外观

干员调配和自选编队中的外观选择是纯展示设置，与技能、模组、持有状态、自选名额分开。现有 2D／3D 棋盘共用 Pixi Spine 人物层。

## 当前覆盖

只核查游戏素材目录里实际有的干员（`charId`），不是明日方舟全部干员。时装按公开游戏皮肤表与 PRTS 页面匹配；页面中的 `时装N名称` 与具体时装名精确对应，不用发行顺序推断 Wiki 图片编号。

当前 `shared/skin-catalogue.js` 收录 **200 名干员、311 套时装**（默认素材 195 名干员 306 套，加联动素材包 5 套），其中 **71 套有可用动态立绘**。仅头像、半身像、完整立绘与战斗本体兼容素材完整的时装进入目录；缺兼容战斗素材的时装未开放选择。官方标为有动态立绘的时装目前都有动态资源；若某套的动态资源缺失，界面标注“动态立绘待补 · 静态预览”。这不是全时装覆盖或全部原作特效还原。

少数时装的原资源没有背面：浊心斯卡蒂「升华」、安洁莉娜「质素访客」「夏卉 FA017」、魔王「追悼」、海蒂「书信零落」。这几套在朝上时仍使用**本套正面**，界面明确标记，不悄悄借用默认服装的背面；浊心斯卡蒂「红女爵」官方只有一个统一战斗模型，界面标“统一战斗模型，正背面共用”。

联动干员的 5 套官方时装（灰烬「游侠」、艾拉「密室」、玛露西尔「泰拉冒险」、丰川祥子「旋律的主人」、结城理「见证荣光」；麒麟R夜刀、焰狐龙梓兰官方没有时装）同样在 `shared/skin-catalogue.js`，素材和记录却属于联动素材包（`data/assets-collab.json` 的 `skins`，`/assets/collab/skins/…`），只在开启「联动干员」的房间里载入并可选；不能用作名片底图。详见 docs/ASSETS.md「The collab pack」。

## 操作与保存

- 干员调配：选中干员，在“外观”中选择时装；头像、半身图和战斗本体使用该选择。
- 自选编队：选择干员时可设置外观。外观按真实干员保存，不按 DIY 槽位保存。
- “默认外观”恢复原普通／精锐图片规则。
- “查看立绘”按需加载完整立绘。已安装动态立绘可播放原骨骼动画及原有前／背景，支持暂停、动作切换、静态切换。
- 动态立绘一律播放，不按 `prefers-reduced-motion` 暂停（2026-11-03 用户决定）；隐藏页面时预览停止动画，关闭预览销毁自己的渲染器并释放资源引用。
- 设置保存于浏览器 `sp.pref.skins`，随干员调配的“导出预设／导入预设”在浏览器间迁移（[OPERATOR-PRESETS.md](OPERATOR-PRESETS.md)），不是账号跨设备数据库同步。
- 预设里外观是独立的 `skins` 项；旧的单独外观文件 `{kind: 'stronghold.skins', v: 1, choices}` 仍可导入，只替换外观。
- 本局确认阶段 `INFO_CHECK` 结束后锁定外观；之后的修改保存给下一局，不中途替换单位。

动态立绘（rel26，2026-11-02 用户决定）：71 套有官方动态立绘的时装全部带上（11 套来自 PRTS，60 套由本地客户端 `arts/dynchars` 解包，图集页为无损 WebP，逐像素 RGBA 与 PNG 一致）。图集页多为直通 alpha；15 套是预乘 alpha，在 `data/assets.json` 标 `pma: true`（`tools/prepare-operator-skins.mjs` 的 `PREMULTIPLIED_DYNAMIC`），其中 11 套的接缝由 `tools/fix-dynamic-edges.py` 修过，用另存的 `<页>.edge.<扩展名>` 与 `.edge.atlas`（rel37）。除「查看立绘」外，rel27 起（2026-11-03 用户决定）凡显示这些时装立绘的地方都实时播放（`public/js/ui/dynamicIllustration.js` 的 cover 模式）：干员调配的列表头像（官方头像取景）、卡片视图和详情立绘（官方半身像取景）、自选立绘框、玩家头像（大厅、同盟座位、成就；对局界面内仍为静态）、名片底图（任意宽度），以及同盟座位卡（默认官方半身像取景）。取景框由离线比对官方头像／半身像与动态立绘静帧得到，存于 `data/assets.json` 的 `skins[id].dynamic.frames`，与下面的静态图同一裁切；第一帧画出后静态图隐藏，任何失败都留静态图。所有立绘共用一个 WebGL 上下文（`public/js/ui/dynamicStage.js`：每帧把屏幕上的立绘排进一张离屏画布，一次绘制后拷到各自的 2D 画布），不限个数、不限帧率（跟随显示器刷新）、分辨率为框的 CSS 尺寸 × devicePixelRatio；离开屏幕的不加载也不绘制；不理会 `prefers-reduced-motion`。比图集本身更细的清晰度只是插值，是素材的上限。客户端里环绕骨骼的 Unity 粒子与网格背景不是 Spine，不在此列。联动时装没有动态立绘。

高清静态立绘（rel30）：`data/assets.json`（联动干员在 `data/assets-collab.json`）的干员精一／精二与时装带 PRTS 原画的 `illustration`／`portraitHD`／`portraitBox`／`portraitScene` 等字段（`tools/prepare-operator-illustrations.mjs`，素材重建见 `tools/assets/hd-art/README.md`）；干员调配、自选、结算、成就统计与对局内详情画高清裁切，同盟座位卡画整张立绘（含场景）。玩家可在自己的座位上「调整立绘」拖动、缩放，精一／精二、静态和动态时装都可以；取景随 room.card 的 artX／artY／artZoom 同步给全房间。名片底图另有「调整位置和缩放」（bgX／bgY／bgZoom）。

## 同步与安全边界

`room.skins {choices}` 为 `{[actualCharId]: admittedSkinId}`，只接受共享目录中绑定到该干员的标识，不接受任意 URL、未知标识、跨干员借用或原型属性键。沿用既有有界消息、重型消息限流及连接顺序。

Session／座位／PlayerState／集群 assignment 独立复制、冻结选择。`m.private.skins` 只发给本人；队友侦察、旁观、Boss 搭档、战斗及结算只携带可见单位自己的 `skinId`，不公开完整个人设置。

皮肤不替换 `charId`、棋子 ID、`spine`／语音身份，不写入共享战斗 def，不改变技能、模组、属性、攻击命中时序、RNG 或结算。未持有干员的替补使用替补实际身份；不能把被替换干员的皮肤套在替补上。不同玩家的同款干员各用自己的选择。

骨骼／图片加载失败时回退默认外观，动态预览失败时回退静态立绘，不影响战斗。召唤物时装、原作独立弹道／技能特效、专属语音不由此功能自动支持。动态立绘中的原骨骼效果与战斗程序化特效是两个不同的系统。

## 素材导入

素材来自公开 PRTS 图片信息接口和经过验证的 `/spine38/` 资源，运行时不热链 Wiki。旧 `/spine/` 可能为 3.5 binary，本项目解析工具要求实际兼容的 3.8 骨骼；每套校验 atlas 页面、PNG 尺寸、骨骼版本／附件及动画。Wiki 图片按其 size／SHA1 校验，再记录 SHA256。动态骨骼、纹理与配置存在并可解析才标为可用动态立绘；不能把游戏表的动态标记当作资源已安装。

展示副本清除骨骼头中仅供编辑器使用的 `imagesPath`／`audioPath`，不改附件、骨骼和动画主体字节；原始下载留在隔离来源库存，并分别记录原始／展示副本哈希。现有琴柳「夏卉 FA317」正背骨骼已转换为独立的 `.display.skel`，主体逐字节及解析结果一致，原件不覆盖、不列入发行素材清单。完整打包仍执行个人路径扫描，不豁免原始美术文件。

工具：

```sh
node tools/prepare-operator-skins.mjs --source <新的隔离素材来源目录> --download
```

扩展目录可用 `--catalogue <已核实的metadata.json>` 与 `--registry shared/skin-catalogue.js`。工具限制来源主机、单文件尺寸、atlas 页数与纹理预算；至多两套同时导入，不重试，遇到403／429停止继续请求。不能在下载目录里运行脚本或第三方工程。

`tools/fetch-assets.mjs` 重建默认素材时保留已收录且文件完整的时装，并将其文件纳入清单与 prune 引用；不为缺失素材发出坏 URL。美术、原始来源、下载库存与缓存不进入 Git。新游戏版本、私有素材清单与公开静态文件必须作为配套材料准备；此本地实现不代表已上传 provider 或部署。

原始立绘、模型、音频等归相关游戏权利方所有。PRTS Wiki 的文字许可不能作为游戏素材再分发的独立授权。

## 验收边界

首批（2026-10-08）以本地真实 HTTP／WS、实际 combat Worker、双人浏览器与真实私有集群 RPC／WS 验证展示同步和重连；独立数值回归比较默认／皮肤的 snapshot、结果、RNG 与 def。浏览器验收由 Main 驾驶、读取截图，使用 Chrome 软件 WebGL 与手机模拟，不是实体手机或硬件 GPU 性能测试。

动态立绘实测耀骑士临光「复现荣光」：原分层、播放时画面变化、暂停画面稳定、动作／静态切换、手机减少动态默认暂停、关闭销毁渲染器。泥岩双人不同外观、正背模型、浊心斯卡蒂仅正面、队友查看、外部旁观与战斗重连也已实测，旁观者不收到被观看玩家的私有配置。

另以精确的本地 404 夹具验证：动态骨骼缺失回退静态立绘，时装图片缺失回退默认半身像，时装战斗骨骼缺失仍显示实际默认 Spine 模型、保留选择。仅该轮明确注入请求及有界对应解码诊断按预期故障处理，原始错误保留，不当作正常无错误运行。上述并非逐套动画人工视觉验收、实体手机测试或与原作逐像素一致性保证。

最终本地回归：581 个测试文件，6206 通过、23 跳过、0 失败；独立官方 golden 六个类别共 283 场景一致，原 JSON 未改。源码／完整素材清单打包 dry-run、翻译、导入边界、语法与默认素材不变检查通过。失败历史和详细证据见本地 `.claude/operator-skins-20261008.md`。本地验收完成后，用户单独授权提交并推送源码；这不包含构建发布镜像、上传 provider 或上线，Git 发布不会改变正式服。
